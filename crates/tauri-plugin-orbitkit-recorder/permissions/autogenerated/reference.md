## Default Permission

Default permissions for OrbitKit Recorder plugin

#### This default permission set includes the following:

- `allow-start-foreground`
- `allow-pause`
- `allow-resume`
- `allow-stop`
- `allow-state`
- `allow-post-standby-notification`
- `allow-get-persisted-state`
- `allow-recover-state`
