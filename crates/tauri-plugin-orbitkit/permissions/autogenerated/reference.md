## Default Permission

Default permissions for OrbitKit plugin

#### This default permission set includes the following:

- `allow-overlay-permission`
- `allow-request-overlay-permission`
- `allow-show-overlay`
- `allow-hide-overlay`
- `allow-open-popup`
- `allow-close-popup`
- `allow-set-mascot-state`
- `allow-emit-menu-action`
- `allow-start-mascot-drag`
