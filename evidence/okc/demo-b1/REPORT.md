## Round 2 review fix (F1 blocker + F2)

**F1 (AC2 + SMOKE B1.4, blocker) — contentShift double-count.** c1fff75 compensated
content by `oldPos - clampedPos` while the flex-centred layout *already* re-centres the
mascot inside the resized window: every unclamped fit pushed Glim off-window (reviewer
repro: 296x296 @(960,480), idle fit -> shift (-76,-100) -> Glim at (-52,-100)). It also
measured `anchorRect` from the OLD geometry because the open fit was not awaited before
`menuOpen = true` (arc jump on open).

Fix — one consistent model, chosen **(b): deterministic placement + clamp-only
compensation**, implemented in the new pure helper `examples/starter/src/lib/windowFit.ts`:

- CSS pins the mascot **bottom-centre** of its window (`.fit-shift` point at
  left:50%/bottom:0), so the mascot's window-local position is a pure function of the
  window size — the DOM can never re-centre on resize.
- For each state (idle content-fit / open menu-fit) the helper computes the window rect
  whose unclamped placement keeps the mascot's **screen position identical**;
  `anchorRect` (RadialMenu K7 contract) is returned in the NEW window coords, so the arc
  hovers exactly above the mascot.
- Only a work-area clamp moves the window away from the ideal rect; that delta is
  compensated 1:1 by a content translate (`shift = ideal - clamped`), so the mascot stays
  put even at screen edges. No accumulation; every fit recomputes from live geometry
  (drag-safe). Open-state padding is above+sides only so the bottom pin stays exact in
  both states.
- `toggleMenu` now `await`s the open fit BEFORE mounting the menu (anchor matches the new
  geometry; race gone). The radial-anchor wrapper lives outside the shifted subtree
  (fit.anchor already encodes the shift).

## What demo-b1 ships

- **Sprite sheets (K7/K8)**: original pixel-art mascot "Glim" (teal blob, NO CuteCare
  assets) as three 128x32 RGBA strips (4 frames of 32x32) generated by the committed,
  dependency-free `examples/starter/scripts/gen-sheets.mjs`; `mascot.kind="sheets"`,
  `scale 3` (integer, pixelated), `anchor bottom-center`, pools
  `idle`/`alert` (ttlMs 8000)/`sleep` in `src/orbitkit.config.json`. Machine-driven
  rendering via `Mascot` (pool pick + TTL + `onMascotState` hints are library code).
- **Arc-anchor menu (K7)**: `layout "arc-anchor"`, 6 items with dotted ids
  (`app.notes/timer/alert/settings/about/quit`), inline `{svg}` icons (K12 sanitizer),
  `spawn` animation with K7 stagger 260/180/40, `headGap 12`. `MascotView` measures the
  mascot bounds and passes `anchorRect` to `RadialMenu`; the `.radial-anchor` wrapper now
  sits at the window origin (`fixed`) as the library's window-coordinate origin requires.
- **Passthrough (K10)**: `mascotWindow.passthrough: true`; `MascotView` starts
  `startPassthrough` with the mascot element plus a live region following the rendered
  menu discs (DOMRects — `RectEdges` shape, `{left,top,right,bottom}`), drag-aware via
  `gesture.isDragged`.
- **fitContent (K9)**: `mascotWindow.fitContent: true`; `MascotView.applyWindowFit`
  sizes/moves the window via `fitWindow` + `clampToWorkArea` + `mascotMonitor`, and
  compensates DOM content (`contentShift`) so Glim and the menu never jump. Idle window =
  content + 24px transparent side padding (keeps passthrough demonstrable); menu-open
  window = mascot ∪ arc + 8px. Animated close shrinks after the stagger wave (480ms);
  instant close (drag) shrinks immediately.
- **Menu wiring**: `alert` → Rust `set_mascot_state("alert")` (TTL auto-revert to idle);
  `timer` → sleep pool for 5s then idle (demo of sticky state); `notes`/`settings` →
  popups (unchanged); `about` logs; `quit` exits. Capabilities add the three window
  setters (`set-size`, `set-position`, `set-ignore-cursor-events`) — `core:default` is
  getters-only. Main window auto-shows the overlay on desktop startup (Android flow
  unchanged); MainView state buttons are idle/alert/sleep; settings popup derives its
  buttons from `mascot.states` automatically.
- Pixel-crisp: all CSS scale transitions on `.mascot-clickable` removed (hover-scaling a
  `scale 3` sheet interpolates = blur).

## okc_SMOKE.md B1 → exact starter interaction (macOS owner script)

1. **Mascot visible, transparent, no frame/shadow** — Launch the built binary
   (`examples/starter/src-tauri/target/debug/starter`). **No click needed**: the
   dashboard opens AND Glim (teal blob) automatically floats frameless above it
   (auto-shown on desktop; always-on-top, `shadow=false`, no decorations). Look: no
   title bar, no shadow box, desktop/paper behind shows through the window's
   transparent padding.
2. **Idle pixel-crisp, feet do not jump** — Watch Glim idle: 6 fps 4-frame loop; body
   breathes (squish), blink on one frame of the cycle; **feet stay on the same
   baseline**; edges are hard pixels (3x integer upscale, `image-rendering: pixelated`,
   no CSS scaling).
3. **Passthrough** — Move the cursor onto the transparent strip **beside** Glim (window
   hugs the sprite with 24px transparent side padding) and click: the click reaches
   whatever is underneath (focuses another app/window), not the mascot. Then hover over
   the blob itself and click: the arc menu opens (blob is a hit region). Hint: gaps
   between menu discs also pass through while the menu is open.
4. **Arc menu above mascot, centre-first, window grows, no jump** — Click Glim: six
   glass discs pop out in an arc **above the mascot** (12px gap), centre pair first,
   then mid pair, then edges (260ms open / 40ms step). The window silently grows to fit
   the arc; Glim does not move a pixel (K9 compensation shift).
5. **SVG icons, tooltips, Esc + click-away close (edges-first)** — Hover any disc: icon
   is a crisp inline-SVG line icon; a native tooltip shows the label
   (Notes/Timer/Alert/Settings/About/Quit). Press `Esc`: discs shrink back
   edge-first (180ms close wave). Re-open, then click the desktop / a transparent area:
   menu closes the same way (window blur path).
6. **Menu "alert" → ~8s alert then idle** — Click the **Alert** disc (bell icon, centre
   pair): Glim switches to the alert sheet (wide eyes, bouncing amber "!") for ~8s and
   reverts to idle by itself (pool `ttlMs: 8000`, machine expiry).
7. **Keyboard ←/→ focus, Enter activates** — Open the menu and press `←`/`→` (also
   `↑`/`↓`, `Home`, `End`): the focus ring walks across the discs; `Enter` activates the
   focused item (recommend focusing **Alert** — `Enter` on Quit exits the app).

Bonus demos: `timer` → Glim sleeps (zzz) for 5s then idles; Settings popup buttons
set idle/alert/sleep; dashboard "Set Alert/Sleep" buttons drive the same states.
